AUTHENTIC IMAGE PLACEHOLDERS

No AI-generated images, stock images, or fabricated project screenshots are included.

When you have genuine screenshots or photographs, put them in this folder and update
src/data/portfolio.js. For example:

image: '/images/nebula-dashboard.png'

Keep imageAlt descriptive. If image is an empty string, the project card uses a small
CSS-built decorative motif instead of pretending it is a real project screenshot.
